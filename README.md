# BubbleRTE
A JavaScript based HTML encoding rich text editor. Created to support my other project of the Bubble communication platform

<h1>⚠️ THIS PROJECT IS STILL VERY EARLY IN DEVELOPMENT</h1>

## Features
<ul>
  <li>Bold</li>
  <li>Italics</li>
  <li>Underline</li>
  <li>Bullet point lists</li>
</ul>

## How does it work
When a button is toggled, the JavaScript code parses it into HTML inserted into the output (e.g. Bold -> <b>)
